# Build A Comprehensive Sea — Android App

This is a complete, buildable Android project generated by Forge. Your app runs inside a native Android WebView.

## Build an APK locally

1. Install Android Studio + Android SDK (compileSdk 34).
2. Open this folder in Android Studio.
3. Run `gradle assembleDebug` (or press the Run button).
4. The APK is at `app/build/outputs/apk/debug/app-debug.apk`.

## Build an APK automatically (GitHub Actions)

Push this project to a GitHub repo. The included workflow `.github/workflows/build-apk.yml` compiles a debug APK on every push. Download it from the Actions tab → build → Artifacts.

## Install on a device

`adb install app/build/outputs/apk/debug/app-debug.apk`
